Step by Step

How to use the result analyser

  1. Start in the Upload tab. Choose the official KTU result PDF from your system and give it a clear batch name, such as the semester, exam month, and department or college result label.
  2. Select Upload and Analyse. The app reads the result file, identifies departments, students, subjects, grades, pass counts, failed subjects, and GPA values using the configured grade scale.
  3. Open Saved Batches when you want to return to a previous upload. From there you can open an older result set for review or delete a batch that is no longer required.
  4. Use Configuration before or after analysis if the grade-to-point mapping needs to be changed. This controls how GPA is calculated, and subject credits can still be adjusted inside an active batch.
  5. Go to Active Batch Results for the main dashboard. Filter by department, review the summary cards, check top students, update subject credits, search the GPA register, and inspect each student's subject grades.
  6. Use the export actions when the review is complete. The Word analysis report includes summary tables and ranked/filtered sections, while the Excel register gives a spreadsheet-ready GPA register for the selected batch.
